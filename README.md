# Expense Tracker

A simple command-line Expense Tracker developed in Python to record and manage daily expenses.

## Features

 Add expenses with categories
 View expense history
 Undo the last expense
 Calculate total and average spending
 Find highest and lowest expenses
 View category-wise spending
 Save expense reports to a text file

## Categories

  Food
  Travel
  Bills
  Shopping
  Other


## Technologies Used

- Python
- Functions
- Lists and Dictionaries
- File Handling
